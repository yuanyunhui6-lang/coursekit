# 功能路线与决策记录（ROADMAP）

> 记录 2026-11-12 与用户的讨论结论，后续开发以本文件为准。

## 已确认的决策

| 议题 | 决定 |
|---|---|
| 推进顺序 | **先推 v1 拿 APK 真机验收，再开发 Phase A**（新功能代码先在本地写，不推） |
| 课表结构 | 简单版：周一~周日 + 课程名 + 开始/结束时间（后续可加单双周） |
| AI 聊天 | 先做**通用设置页**（Base URL / API Key / 模型 / 人格提示词），暂不绑定具体厂商；支持 OpenAI 兼容接口 |
| 技术栈 | 继续 Python + Kivy，不换语言；若未来上架/多端确有需要，先出评估再迁移 |
| 后台通知 | 做，但需明确权限与限制（见 Phase C） |

## Phase A（v1 验收通过后第一批）

1. **左上角实时时钟**：HH:MM + 日期/星期，每秒刷新，跟随系统时间
2. **照片便签**：新建便签、拍照/相册插图、文字、列表、搜索、编辑、删除
3. **课表（简单版）**：周一~周日课程、开始/结束时间、地点；今日课程高亮；"今天第一节课"计算（为 Phase C 提醒做数据准备）
4. **AI 聊天（通用）**：设置页（Base URL / API Key / 模型 / 温度 / 人格名 / System Prompt）、多套人格预设、聊天界面、本地保存对话、可清空；暂不接具体厂商
5. 底部导航扩展：课件 / 作业 / 课表 / 便签 / AI；收藏夹入口移到首页右上角星标按钮

## Phase B

6. **截止时间识别**：OCR 全文里识别"截止/截止时间/上交/deadline/2026-11-20/11月20日/本周五"等；识别到后弹窗询问「是否添加日程/作业提醒」；确认后写入日程并联动现有作业提醒

## Phase C（后台通知，真机验证）

7. **每天第一节课前 1 小时通知**：
   - 系统通知（高优先级渠道），锁屏可亮屏显示，无需打开 App
   - 当天无课不提醒；周末按课表
   - 实现：AlarmManager + p4a 后台 service + 通知渠道；需 `POST_NOTIFICATIONS`（Android 13+）、`SCHEDULE_EXACT_ALARM`（Android 12+ 用户授权）
   - 已知限制：手机重启后需打开 App 一次重排闹钟；荣耀 MagicOS 需加入后台活动白名单
   - 后续可选：静态开机广播接收器（需内嵌 Java 源码），彻底解决重启问题

## Phase D（以后）

- 云同步 / 多端、上架应用商店（release 签名、隐私政策、软著）、AI 讲题/出题、公式识别、导出 Anki 等

## 前置条件备忘

- GitHub Actions 云端构建（不需要本地 Linux；本地 Linux 仅用于想脱离 GitHub 打包时，必须是 x86_64）
- 平板 Android 13+ 真机测试：通知权限、精确闹钟权限、后台白名单
- AI 功能需要可访问的 OpenAI 兼容 API 与 Key；Key 只存本机、不硬编码、不上传
